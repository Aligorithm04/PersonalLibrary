# 📚 Book Library

A simple personal library to keep track of the books you've finished. View your collection, rate what you've read, and add new books as you complete them.

> **Status:** Early version. Core features only, more coming.

## Features

- **View** your list of finished books
- **Rate** each book (1–5 stars)
- **Add** new finished books to your library

## Planned

- Edit and delete books
- Search and filter (by title, author, rating)
- Reading notes / short reviews
- Sort by rating or date finished
- Stats (books per year, average rating)
